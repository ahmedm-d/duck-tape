## Limits

The browser suite does not establish production authentication, arbitrary-repository sandbox execution, live arbitrary-code editing, or automated accessibility certification. UI preview is explicitly reserved as future capability. Q&A may use live inference or its visibly labelled structural fallback; tests require real evidence links in either case. The full browser trace is not persisted; screenshots, successful check names and backend records are retained.

## Final acceptance result

The expanded browser journey passed after backend restart, with all 15 recorded checks and zero browser runtime errors. The newly configured local inference endpoint required a longer bounded Q&A wait; the suite permits up to 120 seconds for evidence-linked Q&A and still fails on missing citations. This latency allowance does not classify structural fallback as successful live inference. Both fresh bug revisions were independently checked through the backend and contained no generated bytecode.
